# BLV Travel

Landing page tour du lịch trong nước, quốc tế và tour đoàn MICE. Website tĩnh viết bằng HTML/CSS/JS thuần.

## Chạy dự án
Mở trực tiếp `index.html` trên trình duyệt, hoặc chạy một server tĩnh:

```bash
npx serve .
```
